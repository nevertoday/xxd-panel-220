上半部分保留原始照片，保持主体身份、结构、姿态、真实质感、自然光影和原有色彩氛围，仅进行轻微高级调色，使其具有艺术杂志、独立出版物与展览图像质感。为适配画幅，可自然扩展环境背景，但不得拉伸、扭曲或改变主体。

下半部分先理解原照片最值得被记住的**核心主题、主体关系、结构走势、情绪气氛与视觉记忆点**，再重构为**稚拙感手绘 Doodle 小品插画**。风格参考轻松、可爱、松弛的手绘小狗涂鸦：不是写实转绘，也不是普通扁平插画，而是先提炼“识别符号”，再组织对象。删去无关细节，只保留最能代表原物的轮廓、姿态、五官/特征、动作和少量环境暗示，使人一眼识别它与上方照片的对应关系。

整体采用 **Naïve Doodle / Whimsical Hand-drawn Illustration** 逻辑：人物、建筑、动物、植物、器物或景观都以**可识别的大轮廓 + 极简特征 + 少量局部纹理 + 小装饰符号**构成。不要追求画得“正确”或“完整”，而要追求“像它”且“有手感”。允许比例轻微夸张、结构适度简化、细节主动省略。

线条是这部分的核心。使用**圆润、松散、略带抖动和停顿感的手绘描边**，像蜡笔、彩色马克笔或粗细轻微变化的签字笔画出来的线。轮廓不要太顺、太直、太工整；允许短线、重复线、歪线、断续线和不完全闭合的边缘，形成自然的 broken contour。外轮廓负责识别，内部只用极少量短笔触暗示毛感、纹理、阴影或层次，避免复杂结构线和整洁矢量线。

上色采用**局部点染而非完整填满**的方式。保留大量白底，颜色只在必要位置轻松出现，可轻微漏白、越线、不均匀，带一点蜡笔或马克笔的干涩笔触感。颜色更像纹理和气氛，而不是把形状填满。整体保持轻盈、透气、亲切，接近“70%留白 + 20%轮廓 + 10%彩色笔触”的画面气质。

构图保持**小尺度主体 / 大面积有意识留白**的关系，根据主体自身的方向、比例和视觉重心自由安排位置，可偏心、贴边、悬置或局部裁切。主体与少量辅助元素形成一个清晰视觉落点，其余空间主动留空，让留白本身参与正负形、疏密、聚散和不对称平衡，形成呼吸感、空间感与精致的编辑秩序。宁可删减，也不要填满。

配色从上方照片中提取**最有生命力、最有亲和力、最能代表画面精神的2–4种颜色**重新调制，整体提亮、提纯、去灰，形成柔和、讨喜、偏 ins 治愈感的手绘配色。可自然转化为奶油黄、蜜桃粉、嫩橙、草木绿、湖水蓝、雾蓝、珊瑚粉等清爽颜色；主色不多，点到为止，避免灰脏、暗沉、荧光色和廉价糖果感。

文字少量介入，不限制语种。可根据主体、地点、动作、情绪或隐喻自由提炼一句短句、一个小标题或少量注记，并以**圆润、稚拙、自然、略带手写感的字形**融入画面，像插画本身的一部分，而不是后加标题。文字应小、轻、可爱、松弛，与图形一起形成温柔的图文关系。

整体呈现**受控稚拙、圆润线条、局部彩色笔触、小尺度主体、大面积艺术留白与轻松图文混排**共同构成的高级视觉效果。避免逐物写实、完整填色、复杂背景、工整矢量线、卡通模板感、3D感和廉价儿童插画感。
